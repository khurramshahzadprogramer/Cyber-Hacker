## 🕶️ About The Project

**CYBER HACKER :: TERMINAL QUEST** is an interactive, cyber-themed
browser game set inside a fictional **AI Labs mainframe**.

You take the role of an ethical hacker 🧑‍💻 who has been called in after
the AI Labs system is compromised. Your mission is to break through **5
security checkpoints**, recover the system, and complete the final
unlock sequence.

> ⚠️ **Mission Status:** `SYSTEM COMPROMISED`
>
> 🔐 **Objective:**
> `BYPASS SECURITY → FIND THREATS → DECODE → INFILTRATE → UNLOCK SYSTEM`

# 🧪 SECURITY LEVELS

## 🔐 LEVEL 01 --- PASSWORD CRACK

**Objective:** Access the AI Labs mainframe using the correct
credentials.

``` text
USERNAME → admin
PASSWORD → AILabs2026
```

🎯 Enter the correct credentials to unlock the next security layer.

------------------------------------------------------------------------

## 🦠 LEVEL 02 --- FIND THE VIRUS

**Objective:** Locate the infected files hidden inside the system.

-   📁 **12 file icons**
-   🦠 **3 infected files**
-   ⏳ **22-second countdown**
-   ❤️ Selecting the wrong file costs a life

> 🔎 Scan carefully. One wrong move can compromise the mission.

------------------------------------------------------------------------

## 🧠 LEVEL 03 --- CODE MEMORY

**Objective:** Memorize and reproduce a randomly generated security
code.

### Challenge Flow

``` text
DISPLAY CODE
     ↓
MEMORIZE
     ↓
ENTER CODE
     ↓
VERIFY
```

⏱️ The code is displayed for a limited time, followed by an answer
window.

If the attempt fails, a shorter second glimpse is provided before the
next attempt.

------------------------------------------------------------------------

## 🧱 LEVEL 04 --- FIREWALL MAZE

**Objective:** Navigate through the randomly generated firewall maze and
reach the exit.

### 🎮 Controls

``` text
⬆️  Arrow Up / W
⬇️  Arrow Down / S
⬅️  Arrow Left / A
➡️  Arrow Right / D
```

📱 On-screen directional controls are also available.

⏳ **Time Limit:** `55 seconds`

> 🧩 Every run can generate a different maze.

------------------------------------------------------------------------

## 🖥️ LEVEL 05 --- SYSTEM UNLOCK

**Final Objective:** Complete the system recovery sequence and reach
**100% progress**.

The final stage includes:

-   📟 System logs
-   📊 Unlock progress
-   ⚡ Terminal feedback
-   🏁 Mission completion sequence
-   🎉 Completion effects

### 🚀 FINAL STATUS

``` text
[ SYSTEM RESTORED ]
[ SECURITY BYPASSED ]
[ DATA RECOVERED ]
[ MISSION COMPLETE ]
```

# 🏆 SCORING SYSTEM

Your score is influenced by successful actions and level completion.

``` text
🎯 Complete Challenges
      ↓
⭐ Earn Score
      ↓
🏆 Beat High Score
      ↓
💾 Save High Score
```

The game uses browser `localStorage` to retain the high score.

# ❤️ LIVES & GAME OVER

You begin the mission with:

``` text
❤️ ❤️ ❤️
```

Mistakes during certain challenges can cost a life.

When all lives are lost:

``` text
☠️ GAME OVER
```

The player can restart the mission and attempt the security breach
again.
